# Assignment 
Write a python program to calculate the first 10,000 terms of this series, multiplying the total by 4: 1 - 1/3 + 1/5 - 1/7 + ...

# Code 
total = 0.0
for i in range(10000):
    term = (-1)**i / (2 * i + 1)
    total += term
result = total * 4
print(result)

# Output 
3.141592653589793
